---
title: "Introduction"
---

The OCF Core API lets developers create, issue, and manage digital collectibles for proof-of-attendance, achievements, credentials, and other participation-based experiences.

Using the API, you can create projects, define collectibles, issue tokens to collectors, manage collector identities, and query token distribution. The API is designed for applications that need to represent meaningful moments, actions, or accomplishments as collectible digital records.

At the center of the API are three core concepts:

- Collectibles are the items or credentials that can be issued.
- Tokens are individual issued instances of those collectibles.
- Collectors are the people or accounts that receive tokens.

The API also supports project-based access control, metadata schemas, batch issuance, privacy controls, and optional publisher channel registration for supported networks.

These docs explain how to authenticate, structure your data, create collectibles, issue tokens, and retrieve information about collectors, collectibles, and issued tokens.
